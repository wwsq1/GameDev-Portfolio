North Station — 3D Cooperative Survival Game

Engine: Godot 4
Status: In development
Source code: Private

A cooperative survival game set at an isolated Arctic research station.

Players must explore, collect resources, maintain electricity and heating, and survive increasingly dangerous nights.

Systems implemented or prototyped:

- 3D first-person character controller
- Sprinting, crouching and jumping
- Object interaction using raycasting
- Item pickup, dropping and throwing
- Four-slot inventory system
- Interactive doors and switches
- Generator and connected lighting
- Dynamic day/night cycle

Multiplayer gameplay is a planned feature.
